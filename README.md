# Post Box with Character Counter (mstlab)

## Requirements Implementation
1. **Controlled textarea** for the post content.
2. **Live counter** below it (e.g. `45 / 100`).
3. **Red message** `"Limit exceeded"` when character count exceeds 100.
4. **Disable Post button** when text is empty or over the limit.

## Getting Started
```bash
npm install
npm run dev
```
